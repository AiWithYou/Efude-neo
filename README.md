Efude-neoは、852wa氏の[Efude](https://github.com/852wa/Efude)をもとにした派生版です。筆圧に対応したブラシ、レイヤー編集、コマ割りなど、イラストから漫画まで制作できます。元プロジェクトの作者と貢献者に敬意を表します。

![Efude-neoでイラストを編集中の画面。キャンバスの横にブラシ、カラー、ツール設定が並びます。](docs/images/screenshot.png)

> **公開テスト版です。** 開発中のため、バージョンによってファイルや設定が変わることがあります。大切な作品はバックアップを取ってください。

## ダウンロードと起動

**対応環境：Windows 10 / 11（64ビット）。** ペンタブレットはWindows InkまたはWinTabで使えます。

[Efude-neoのダウンロードページ](https://github.com/AiWithYou/Efude-neo/releases/latest)で、次のどちらかを選びます。

| 配布ファイル | 起動方法 |
| --- | --- |
| `Efude-v<バージョン>-windows-x64.zip`（ポータブル版） | 好きな場所に展開し、中の `efude.exe` を起動します。インストールは不要です。 |
| `Efude-v<バージョン>-windows-x64.msi`（インストーラー） | ファイルを開き、セットアップの案内に従ってインストールします。 |

未署名のビルドでは、初回起動時にWindows SmartScreenの警告が出ることがあります。このリポジトリの配布ページから取得したファイルであることを確認し、「詳細情報」→「実行」で起動できます。

元のEfudeとは配布が別です。上のリンクから **Efude-neo** をダウンロードしてください。

## はじめて描く

1. **「ファイル → 新規…」**（Ctrl+N）でキャンバスの寸法を選び、「作成」を押します。
2. **「ブラシ」パネル**でブラシを選び、「カラー」で色、「ツール」でサイズを調整して、キャンバスに描きます。
3. **Ctrl+S**で作品を `.efude` 形式で保存します。初回は保存先とファイル名を選びます。
4. 画像を共有するときは **「ファイル → 書き出し…」**でPNGまたはJPEGを選びます。

`.efude` はレイヤーや作品の設定を保持する編集用の形式です。PNG・JPEGに書き出した後も、描き直すための `.efude` を残してください。PNGは透明部分を保持し、JPEGは白背景になります。他のアプリとの受け渡しにはレイヤー付きPSDも使えますが、Efude固有の情報をすべて保持できるわけではありません。

よく使う操作（初期設定）：

| 操作 | キー・マウス操作 |
| --- | --- |
| 取り消し / やり直し | Ctrl+Z / Ctrl+Y または Ctrl+Shift+Z |
| キャンバスの拡大・縮小 | マウスホイール |
| キャンバスの表示位置を移動 | スペースキーを押しながらドラッグ |
| 全体を表示 | Ctrl+0 |

詳しい手順やショートカットは[ユーザーガイド](docs/USER_GUIDE.md#ユーザーガイド)とアプリ内のヘルプで確認できます。

## 主な機能

| やりたいこと | 使える機能 |
| --- | --- |
| イラストを描く | ペン・鉛筆・水彩などのブラシ、色混ぜ、手ブレ補正、筆圧カーブ、入り抜き、先端・グレインの質感設定。ブラシセットの取り込み・書き出しもできます。 |
| レイヤーで絵を組み立てる | ラスター・ベクターレイヤー、フォルダー、合成モード、クリッピング、マスク。ベクターの線はあとから制御点で編集できます。 |
| 絵の一部を編集する | 矩形・投げ縄・自動選択などの選択ツール、選択ペン、クイックマスク、移動・変形・メッシュ変形、コピー＆貼り付け、塗りつぶし。 |
| 色や仕上がりを調整する | ぼかし、シャープ、トーンカーブ、色相・彩度・明度、モザイク、線の太さなどのフィルター。適用前後をプレビューできます。 |
| 漫画を制作する | 裁ち落とし・仕上がり線つきの原稿、コマ割り、トーン、集中線・流線、縦書きのフキダシ、複数ページの管理と一括PNG出力。 |
| 描きやすい表示にする | キャンバスの回転・反転、拡大縮小、定規・対称定規、透明部分の市松表示、複数の作品を開くタブ。 |

PNG・JPEG・BMP・GIF・PSDの読み込みに対応しています。画像を開いて描き足し、`.efude` として保存することもできます。

## 下絵・仕上がり確認・制作記録

- **下絵ガイド** — 「表示 → 下絵ガイド」から画像を描画レイヤーの下に置き、不透明度・位置・倍率を調整できます。ガイドは作品に保存され、通常のPNG・JPEG・PSD書き出しには入りません。
- **塗り残し・消し忘れチェック** — 「編集 → 塗り残し・消し忘れチェック…」で透明穴・孤立点・仕上がり範囲外の候補を強調します。作品の画素は変更せず、候補を押して拡大確認できます。
- **制作タイムラプス** — 「記録 → タイムラプスの記録を開始…」で制作過程を記録し、MP4・MJPEG AVIに書き出せます。下絵ガイドを動画に含めるかは開始時に選びます。MP4では仕上がり時間・完成画像の静止時間・動画サイズ・収め方を指定できます。
- **操作マクロ** — レイヤーの作成・複製・名前・表示・不透明度・合成モードの操作を記録し、対象や手順を編集して別の作品で再生できます。再生は1回の取り消しで戻せます。ブラシの線や画面操作は記録対象外です。

**MP4出力には、`libx264`を含むFFmpegが別途必要です。** 書き出し画面で実行ファイルを指定するか、PATHにあるFFmpegを使います。AVI出力にはFFmpegは不要です。詳しくは[ユーザーガイドの「下絵ガイド・タイムラプス・マクロ」](docs/USER_GUIDE.md#ユーザーガイド)を参照してください。

<details>
<summary>制作記録の補足とデータの保存先</summary>

- MP4の仕上がり時間は、完成画像の静止時間を含めて1〜600秒です。MP4・MJPEG AVIとも30fpsです。
- 記録を終了した後も連番JPEGが残り、「記録 → 以前の記録から動画を書き出す…」で再利用できます。AVIが1.9GBを超える場合はJPEGフレームを利用してください。
- 0.3で保存したマクロ（旧マクロを編集して保存したものを含む）は0.2では読めません。旧マクロは0.3でも読み込めます。0.2用のファイルを残すときは「別のマクロとして保存」を選んでください。

| データ | 保存先 |
| --- | --- |
| タイムラプスの連番JPEG | `%LOCALAPPDATA%\Efude-neo\timelapse\` |
| 作業の復旧データ | `%LOCALAPPDATA%\Efude-neo\recovery\` |
| 操作マクロ | `%APPDATA%\Efude-neo\macros\` |

</details>

## 自動バックアップと作業の復旧

保存済みの作品は、作品ファイルの隣の `.efude-backups` フォルダーへ定期的にバックアップできます。「ファイル → 環境設定…」で間隔と保存する世代数を設定します。

未保存の作品も含め、変更のある各タブの復旧データを定期的に保存します。異常終了後の起動時、または「ファイル → 作業の復旧…」からサムネイルを選ぶと、未保存の新しいタブとして復元されます。元の作品ファイルは上書きしないので、復元した作品は別名で保存してください。正常終了時には、その実行中に作成した復旧データを削除します。

## ソースからのビルド

<details>
<summary>開発者向けの手順と資料</summary>

Rust 1.95以降が必要です。リポジトリのルートで次を実行します。

```powershell
cargo run -p efude-app --release
```

ワークスペースは描画エンジンの各クレート、ライブラリの `efude`、アプリの `efude-ui`・`efude-app` で構成されています。ファイル形式は[仕様資料](docs/spec)、リリースの作成手順は[リリース手順](docs/RELEASING.md)を参照してください。

</details>

# 仕上げチェック・動画出力・マクロ編集・取り込み確認

## 塗り残し・消し忘れチェック

「編集 → 塗り残し・消し忘れチェック…」から開く。初期の対象は選択中の描画レイヤーで、フォルダーを選択している場合はその中の描画レイヤー。

- 透明穴: キャンバスの端につながっていない小さな透明領域。
- 孤立点: 小さく独立した描画領域。斜めにつながる線も一つの領域として扱う。
- 範囲外: 指定した仕上がり範囲からはみ出した描画。

対象レイヤー、透明とみなすアルファ、穴・点の最大面積を調整して「チェック」を押す。面積の単位はキャンバスの画素数で、0にするとその種類の検出を止める。初期値はアルファ8、穴64画素、点16画素。透明穴を探す場合は不透明な背景を対象から外す。表示・不透明度・親フォルダー・マスク・クリッピングは描画中の見え方に合わせ、非表示や不透明度0の層は除外する。

仕上がり範囲はキャンバス全体、漫画の仕上がり枠、指定矩形から選べる。指定矩形の右端・下端は含まない。漫画の塗り足しや意図した点も候補になるため、候補を押して拡大確認し、不要な候補は「対象外」にできる。「候補を強調」で確認用の枠を切り替える。

作品の画素・Undo履歴は変えない。編集や設定変更後の古い結果は消し、もう一度チェックする。表示は先頭500候補までで、件数は全候補を数える。大きすぎる画像や極端に複雑な領域は、明示したエラーで停止する。白い不透明画素の塗り残しや、他の描画とつながった不要な線を意図から判断する機能ではない。

## タイムラプス

「記録 → タイムラプスの記録を開始…」で記録し、「動画を書き出す…」でMP4またはAVIを選ぶ。「以前の記録から動画を書き出す…」で記録フォルダーを再利用できる。

MP4はH.264・30fps。仕上がり時間は1〜600秒で、完成画像の静止時間を**含む**。例えば30秒・完成画像2秒なら、制作過程28秒と完成画像2秒になる。1/30秒単位に丸めた実際の長さを画面に表示する。記録の最初と最後を残し、途中は指定時間に合わせて間引き・繰り返しする。

寸法は記録時の寸法、長辺720／1080画素、縦1080×1920、横1920×1080、正方形1080×1080。「全体を収める」は余白を白にし、「中央で切り抜く」は中央を基準に切り抜く。プレビューと出力は同じフレームの選び方・配置を使う。AVIは従来どおり記録時の寸法・30fpsで、時間指定や切り抜きは適用しない。

MP4には`libx264`を含むFFmpegが必要。PATHにある`ffmpeg`を使い、見つからない場合は書き出し画面の「指定…」から実行ファイルを選ぶ。指定は設定に保存する。FFmpegは本体に同梱していない。AVIにはFFmpegは不要。

最後の編集の記録を確定してから書き出す。欠落・破損したフレームは成功として扱わない。変換中も別の文書の記録は続けられる。進捗画面で中止でき、正常に完成した動画だけを保存先に置く。失敗や中止では既存の保存先ファイルを保持する。

## マクロの対象と手順編集

「記録」メニューのマクロ記録・実行・手順編集から操作する。記録対象はレイヤーの作成、複製、名前、表示、不透明度、合成モード。

手順の追加・削除・並べ替え、操作と値の変更ができる。対象は次から選べる。

| 対象 | 動作 |
| --- | --- |
| 実行開始時のレイヤー | 実行前に確認したレイヤーに固定する。 |
| その時点の選択レイヤー | 作成・複製などによる選択の変化に従う。旧マクロの動作もこれ。 |
| 名前を指定したレイヤー | 実行前に文書内のレイヤーとの対応を確認する。 |
| 先行手順で作成・複製したレイヤー | 手順IDと、その手順で増えたレイヤー内の順番で指定する。 |

同名レイヤーが複数ある場合や対象が見つからない場合は、自動で決めず対応を選ぶ。開始対象と名前の対応は実行前に固定し、途中の名前変更でも対象を変えない。複製フォルダー内の順番は文書のレイヤー順、0から始まる。作成元の構造が違う場合は対象手順を確認する。

削除・並べ替えで生成前のレイヤー参照になった場合などは、保存できない。実行中に対象不足などで失敗した場合は全手順を戻し、以前のRedoも保持する。成功したマクロはUndo一回で戻せる。

保存形式は`.efmacro.json`のversion 2。旧version 1は読み込む際に従来の選択レイヤー依存の動作を保ち、編集・保存するとversion 2になる。既存マクロの「保存」はそのファイルを更新し、「別のマクロとして保存」は新しいファイルにする。

## ブラシセットの取り込み

ブラシ欄の「読み書き・入力ログ・比較 → ブラシセットを読み込み…」で、適用前の確認を開く。初期動作は今のブラシへの追加。

取り込むブラシを個別に選び、同じ内容は名前が違っても省く。同名で内容が違うものは、別名で追加、今のものを残す、同名を置き換える、から選ぶ。追加・省略・置換・適用後の合計と名前変更を表示する。「セット全体を置き換え」では今のブラシを外す本数も表示する。

全体の計画が有効な場合だけ一括適用する。確認後に既存のブラシ設定が変わった場合は「現在のブラシで再確認」する。直後の「直前の取り込みを戻す」で元のセットに戻せる。取り込み後にサイズ・選択を変えた場合はその変更を保つ。ブラシ内容をさらに編集した場合は、その編集を上書きしないよう復元を止める。

## 漫画作品の一括PNG出力

作品の書き出し先を選ぶと、対象ページ数・未保存ページ数・出力ファイル・同名PNGを確認する画面を開く。

- 「現在の内容で書き出す（原稿は保存しない）」: 開いている全タブの原稿は、確認を開いた時点の内容を使う。閉じたページは保存済みの原稿を使う。
- 「変更したページをすべて保存してから書き出す」: 確認した変更を保存してからPNGを作る。確認後にページの変更・閉じ直し・別名保存があれば、保存を止めて確認の更新を求める。確認時に閉じていたページを開いて変更した場合も同じ。

「現在の内容で確認を更新」で取り直せる。保存方法の選択は保ち、PNGの置き換えの確認はやり直す。閉じた原稿や既存PNGが確認後に外部で変更された場合も、古い確認を使って上書きしない。同名PNGは「確認したPNGを置き換える」を選んでから出力する。

通常の保存と同じ処理順でページを保存し、途中で失敗した場合はPNGを出さない。先に保存できたページは保存済みとし、その後に編集した内容は未保存のまま保つ。保存済みの復旧データは片づけ、保存後の編集の復旧データは残す。全ページのPNGを一時領域に作成してから置き換え、置き換え中の失敗は元の出力を復元する。外部から変更された出力は消さず、復元できない場合は原本の退避先を知らせる。複数ファイルの置換は電源断まで含めた一括トランザクションではない。

## 起動と確認

追加のRust依存ライブラリはない。Rust 1.95で起動する。

```powershell
cargo run -p efude-app --bin efude
```

主要な確認は、キャンバスの判定・通常の描画とのアルファ一致、UIへのクリック入力、マクロの一括Undoと失敗復元、取り込みの復元、全タブの未保存出力、保存・PNG置換の失敗時の復元。FFmpegとFFprobeがある環境では、実際にMP4を作り、コーデック・寸法・秒数・最初と最後の画像・変換中の中止・別原稿の記録継続を確認する。

```powershell
# FFmpegの確認を省略させずに全体を検証する
$env:EFUDE_REQUIRE_FFMPEG = '1'
cargo test --workspace
```
